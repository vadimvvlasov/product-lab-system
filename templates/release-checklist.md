# Release Checklist — [EXP-ID]

## До разработки
- [ ] Ссылка на experiment brief есть.
- [ ] Измеряемая гипотеза и primary metric определены.
- [ ] Scope и out-of-scope заданы.
- [ ] Известные product/security/privacy risks записаны.
- [ ] Решение о rollout/rollback определено.

## Код и качество
- [ ] Coding agent получил критерии приёмки и ограничения.
- [ ] Diff и новые зависимости проверены человеком.
- [ ] Unit/integration/e2e тесты добавлены по необходимости.
- [ ] Negative cases, пустые состояния и ошибки проверены.
- [ ] Авторизация и изоляция пользовательских данных проверены.
- [ ] Нет секретов и чувствительного пользовательского содержимого в логах/аналитике.
- [ ] Для AI/SQL-функций проверены ограничения, инъекции, таймауты и валидность результата.

## Измерение и rollout
- [ ] События аналитики проверены на dev.
- [ ] Источник/campaign/experiment ID фиксируются.
- [ ] Dashboard или запросы для review готовы.
- [ ] Guardrail-метрики доступны.
- [ ] Smoke test на dev пройден.
- [ ] Production rollout выполнен по принятому процессу.
- [ ] Smoke test после deploy пройден.
- [ ] Rollback / выключение функции проверены или понятны.
- [ ] Назначена дата/условие decision review.

## Коммуникация
- [ ] Пост/объявление соответствует правилам площадки.
- [ ] Тестовый сценарий и ограничения объяснены.
- [ ] Пользователь знает, какие данные обрабатываются и куда они передаются.
