# Release Checklist — [EXP-ID]

Gate G3 и Definition of Done экспериментальной функции. Копируется в PR или в эксперимент с `method: feature | launch`.

**Уровень риска:** низкий / высокий.
- **Низкий** — UI, тексты, вёрстка, новые события аналитики без PII; данные, авторизация, AI, SQL, платежи и миграции не затронуты. Достаточно базового блока.
- **Высокий** — затронуто хоть что-то из перечисленного. Базовый и полный блоки.

## Базовый — для всех релизов
- [ ] Эксперимент прошёл G2; scope и out-of-scope заданы; coding agent получил постановку по [[40-deliver]].
- [ ] Основной сценарий работает end-to-end; критерии приёмки покрыты тестами, весь набор тестов зелёный.
- [ ] Diff и новые зависимости проверены человеком.
- [ ] События видны в dashboard/logs на dev, совпадают с планом эксперимента, `experiment_id` и source/campaign сохраняются.
- [ ] Smoke test на dev и после deploy пройден.
- [ ] Rollback / feature flag понятен.
- [ ] Назначены дата/условие review и кто проверит результаты.

## Полный — при высоком риске
- [ ] Секреты и миграции проверены; миграции обратно совместимы.
- [ ] Ошибки, таймауты и деградация зависимостей обработаны.
- [ ] Тесты: integration/API, e2e основного пути, negative/security cases по риску.
- [ ] Вручную на dev проверены пустые, ошибочные и пограничные состояния.
- [ ] Авторизация и изоляция данных правильного пользователя/тенанта проверены.
- [ ] Нет секретов и чувствительного пользовательского содержимого в логах/аналитике.
- [ ] Для AI/SQL-функций проверены ограничения, инъекции, таймауты и валидность результата.
- [ ] Error и latency можно отличить от отказа пользователя; guardrail-метрики доступны; для критичных отказов есть alert/порог.
- [ ] Dashboard или запросы для review готовы.
- [ ] Production rollout — по принятому процессу, при возможности для ограниченной группы; rollback проверен.
- [ ] Документация отражает фактическое состояние.
- [ ] Платная функция: оплата включается только после прохождения этого чек-листа ([[00-model]], § Правило оплаты).

## Коммуникация — если функцию анонсируют
- [ ] Пост/объявление соответствует правилам площадки.
- [ ] Тестовый сценарий и ограничения объяснены.
- [ ] Пользователь знает, какие данные обрабатываются и куда они передаются.
